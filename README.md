# Primer Examen - MANACO Landing 
 Desarrollado por: Maritza Lurici Cárdenas  

Este proyecto corresponde al primer examen parcial de Tecnologías de Internet.  
La tarea consiste en desarrollar una landing page para MANACO, aplicando buenas prácticas de HTML5 semántico, accesibilidad (a11y), SEO básico y diseño responsive (mobile-first).
Que nos vaya bien a todos jij besos.


## Accesibilidad (a11y)

Se implementaron las siguientes mejoras de accesibilidad:

- Skip link: Enlace invisible que aparece al navegar con teclado, permitiendo saltar directamente al contenido principal.
- Roles ARIA: Uso de roles semánticos (banner, navigation, main, article) para mejorar la interpretación de lectores de pantalla.
- Etiquetas ARIA: aria-label en botones para describir su función a usuarios con discapacidad visual.
- Navegación por teclado: Todos los elementos son focusables y navegables con teclado (Tab/Enter).
- Contraste de colores: Se validó que los colores cumplan con relación de contraste 4.5:1 usando la herramienta WebAIM Contrast Checker.
- Pruebas con teclado: Se verificó la navegación completa usando solamente el teclado.
